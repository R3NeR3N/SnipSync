# Premiere Pro 取り込み確認のお願い（動画編集がはじめての方向け）

> このメモは、SnipSync が書き出した「タイムラインファイル(.xml)」を
> **Adobe Premiere Pro に読み込むと音声トラックがどうなるか**を確認していただくためのものです。
> 専門知識は不要です。書いてある通りにクリックして、見えたものを報告するだけで完了します。
> 所要時間の目安: **15〜20分**。

---

## 0. まずは言葉の説明（3つだけ）

| 言葉 | かんたんな意味 |
|---|---|
| **トラック** | 編集画面の下半分にある「横の段」。映像の段、音の段が何段も重なっています。 |
| **波形（はけい）** | 音が入っている部分に表示される「ギザギザの絵」。これが無く真っ平らなら、その段は**無音（音が入っていない）**です。 |
| **シーケンス** | 「編集中の1本のタイムライン」のこと。ファイルを読み込むと自動で1本できます。 |

確認していただきたいのは要するに **「音の段(トラック)が何段でき、どの段に音が入っているか」** の1点だけです。

---

## 1. 用意するもの

別途お渡しする **フォルダ1つ**（中に2ファイル）:

- `2026-06-20 10-56-29.mp4` … 元の動画
- `2026-06-20 10-56-29_snipsynced.xml` … SnipSync が作ったタイムラインファイル

> ⚠ この2つは**必ず同じフォルダに入れたまま**使ってください。バラバラにすると動画が見つからなくなります。

必要なソフト: **Adobe Premiere Pro**（バージョンはお使いのもので構いません）。

---

## 2. テストは2回します（両方おねがいします）

- **テスト①**: 元の動画(.mp4)をそのまま読み込む → 「本来の正しい段組み」を見る（比較の基準）
- **テスト②**: SnipSync の .xml を読み込む → 「実際にどうなるか」を見る

①と②を比べることで、SnipSync の出力が正しいか／おかしいかが分かります。

---

## 3. 準備：プロジェクトを作る

1. Premiere Pro を起動します。
2. 最初の画面で **「新規プロジェクト」** をクリック。
3. プロジェクト名は何でも構いません（例: `確認用`）。保存場所もそのままで **「作成」** をクリック。
4. 編集画面が開けば準備完了です。

---

## 4. テスト①：元の動画(.mp4)を読み込む

1. 画面上のメニュー **「ファイル」→「読み込み...」** をクリック。
   （または `Ctrl + I` キー）
2. お渡ししたフォルダの中の **`2026-06-20 10-56-29.mp4`** を選んで **「開く」**。
3. 画面左下あたりの **「プロジェクト」パネル**（読み込んだ素材が並ぶ場所）に、
   動画ファイルが1つ追加されます。
4. その動画ファイルを、**画面下半分のタイムライン（編集エリア）へドラッグ＆ドロップ**します。
   - 「クリップの不一致に関する警告」が出たら **「現在の設定を維持」** または **「OK」** で進めてください（どちらでも結果に影響しません）。
5. これで元動画がタイムラインに並びました。

### 👀 ①で見て、メモすること
- **音の段（A1, A2, A3 … と書かれた横の段）は全部で何段ありますか？**
- そのうち **波形（ギザギザ）が入っている段はどれですか？**

> 💡 ここで見えた段数が「**本来あるべき正しい数**」です。
> （この動画は音声が4種類入っているので、おそらく **4段** になるはずです）

### 📸 できれば
タイムライン全体が写るように**スクリーンショット**を1枚撮ってください（撮り方が分からなければ飛ばしてOK）。

---

## 5. テスト②：SnipSync の .xml を読み込む

1. メニュー **「ファイル」→「読み込み...」**（`Ctrl + I`）をクリック。
2. お渡ししたフォルダの中の **`2026-06-20 10-56-29_snipsynced.xml`** を選んで **「開く」**。
3. 自動で新しい**シーケンス（タイムライン）**が作られます。
   - 「プロジェクト」パネルに `Auto-Editor Media Group` などの名前のシーケンスが増えます。
   - それを**ダブルクリック**すると、タイムラインに中身が表示されます。

### もし映像・音が「オフライン」「メディアがありません」と出たら（再リンク）

赤い画面や「オフライン」という表示が出たら、動画の場所を教え直すだけで直ります:

1. 「プロジェクト」パネルで、赤く（オフライン）なっている動画を**右クリック**。
2. **「メディアをリンク...」** をクリック。
3. **「検索」** ボタンを押し、お渡ししたフォルダの **`2026-06-20 10-56-29.mp4`** を選びます。
4. **「OK」**。これで映像と音が表示されます。

### 👀 ②で見て、メモすること（ここが本番です）
- **音の段（A1, A2 …）は全部で何段ありますか？**（← 一番重要）
- **波形（音）が入っている段はどれですか？**（例: A1とA2だけ、など）
- **真っ平ら＝無音の段はどれですか？**（例: A3〜A8は空、など）
- **映像の段（V1）に映像クリップは並んでいますか？**
- 動画が**細かく分割（カット）されて並んでいますか？**（SnipSync は無音部分をカットするので、ぶつ切りになっているのが正常です）

### 📸 できれば
タイムライン全体（段組みが全部見えるように）の**スクリーンショット**を1枚。

---

## 6. 報告のしかた

下の表を埋めて返信していただくだけで完了です。コピーして使ってください。

```
■ テスト①（元の動画 .mp4 をそのまま読み込み）
  音の段は全部で … 段
  音が入っている段 … （例: A1, A2, A3, A4）

■ テスト②（SnipSync の .xml を読み込み）
  音の段は全部で … 段
  音が入っている段 … （例: A1, A2）
  無音（真っ平ら）の段 … （例: A3, A4, A5, A6, A7, A8）
  映像の段 V1 … ある / ない
  動画はぶつ切りに並んでいる … はい / いいえ

■ 気づいたこと（自由記入）
  （例: ①は4段なのに②は8段に増えていた、後半の段はずっと無音だった、など）
```

可能であればスクリーンショット2枚（①と②）も添えてください。

## 7. （依頼者向けメモ・テスターは読まなくてOK）

- 確認したいのは「現行の**無改変**xmlが Premiere Pro 自身で 4段→8段に増えるか／空トラックが出るか」。

- テスト②が「8段・うち後半が無音」なら症状は Premiere でも実在 → 修正(A案=4段へ集約 / B案=wav分離参照)へ進む。
- テスト②が「4段・全部に音」なら Premiere では問題なし（8段化は DaVinci 固有）→ 修正不要、DaVinci 向け注記のみ。
