## 1. 実行環境

`.venv` と `venv` は uv で作り直し済み（Python 3.13）。`SnipSync` フォルダで実行する。

```powershell
.venv\Scripts\python.exe src\app.py
```

初回の処理で auto-editor 31.7.2（約45MB）を取得し、SHA-256 を照合する。初回の字幕生成では Whisper モデル（large-v3-turbo は約1.6GB）が自動で取得される。話者分離をオンにすると、初回だけ約35MBのモデルを取得する。

EXE を作って試すとき:

```powershell
.venv\Scripts\python.exe scripts\fetch_auto_editor.py
.venv\Scripts\python.exe -m PyInstaller build\app.spec
```

| V2 | **マーカー（Premiere）** | 出力=Premiere Pro、マーカーを追加=オン | `.xml` を取り込めて、シーケンスマーカーが出る。位置が合う | |

## 3. うまくいかなかったとき

- 取り込めない／壊れる: 使った設定・素材の種類（fps・音声トラック数・モノラルかステレオか・解像度）・NLE の版を控えて報告。**取り込めなかった `.fcpxml` / `.xml` を保存しておく**。
- マーカーが原因かの切り分け: 「マーカーを追加」をオフにして同じ素材を処理し、取り込めるか比べる。
- 倍速が反映されない: 「無音の扱=カットする」に戻せば従来どおり。
- 字幕の位置が合わない: 「字幕をカット境界で分割」をオフにして比べる。
- auto-editor の取得に失敗する: 社内ネットワークなどで GitHub に届かない可能性。`scripts/fetch_auto_editor.py` を別の環境で実行し、`%APPDATA%\SnipSync\bin\auto-editor-31.7.2.exe` に置く（SHA-256 が合わなければ使われない）。

## 4. 既知の制限

- **ライセンスキー無しの auto-editor は、メディア書き出しの解像度を 3200×1800 以下へ縮小する**。NLE 用のタイムライン出力は制限なし。
- 同梱の auto-editor に mp3 / m4a / aac のエンコーダーが無い。音声のみのメディア書き出しは WAV になる。
- 話者分離は日本語専用モデルではない。実音声での精度は V9 で確認する。
- フィラー語（「えー」「あのー」）の自動カットは見送り。Whisper がフィラーをほぼ書き起こさないため。
- NG テイク（言い直し）の検出は未実装。
- 倍速モードの字幕境界・マーカー位置は、NLE のクリップ位置と最大1フレームずれることがある（等速のみなら一致）。
