## SnipSyncについて

**SnipSync** は、動画編集の最も面倒な作業を自動化するWindows向けのスタンドアロン・デスクトップアプリケーションです。**動画だけでなく、録音した音声ファイルも処理できます。** 動画・音声ファイルをドロップするだけで、SnipSyncが以下の処理を全自動で行います。

1. **無音部分を自動検知・除去** — `auto-editor` を使用し、設定可能な音量閾値で無音区間を検出します。
2. **そのままインポートできるタイムラインデータを出力** — レンダリング不要で、選択した形式（.fcpxml / .xml）を書き出します。
3. **完全同期された字幕ファイル（.srt）を自動生成** — 内蔵AIエンジン `faster-whisper` が高精度な字幕を出力します。

字幕パイプラインは「カット済みの音声」に対してWhisperを実行するため、`.srt` のタイムコードがタイムラインと完全に同期します。他ツールでよく問題になるタイムコードのズレが原理的に発生しません。

> 🔒 **録音・録画のデータは、PC の外へ出ません。** 無音カット・文字起こし・話者分離は、すべてこの PC の中で動きます。AI モデルを一度取得すれば、**インターネットにつながっていなくても**、動画・音声を編集できます。通信するのは、モデルや GPU 用の部品の初回の取得と、1 日 1 回の更新の確認（オフにできます）だけで、動画・音声のデータは送りません。例外は、清書で、文章を自分でチャットに貼るときだけです（貼った先のサービスへ送られます）。

Pythonのインストール不要。SnipSyncは単一の `.exe` ファイルとして動作します。

**自動のあとに、手でも整えられます。** 波形の区間を、ドラッグか数値で選んで、削除・倍速にできます。字幕の確認・編集画面で字幕を消すと、その区間の映像・音声も同時にカットして、字幕とタイムラインを書き直せます。保存した編集は、あとで開き直して続けられます。

**会議の議事録づくりにも使えます。** Zoom や Teams、対面で録った会議の音声を渡すと、無音を詰めた音声を話者ごとに分けて文字に起こし、`.txt` か `.md` で書き出します。話者には「山田」「佐藤」のような名前を付けられるので、議事録の下書きにそのまま使えます。動画がなくても、音声ファイルだけで処理できます。文字起こしと話者の分け方には誤りが残るので、字幕確認画面で直してから保存してください。

## ✨ 主な特徴

| 機能 | 詳細 |
|---|---|
| 🔇 **無音自動カット** | あらゆる動画ファイルの無音部分を自動検知・除去 |
| 🎬 **NLEタイムライン出力** | DaVinci Resolve / Final Cut Pro / Premiere Pro向けのタイムラインを即時出力 |
| 📝 **AI字幕自動生成** | `faster-whisper` で `.srt` を生成 — タイムコードのズレはゼロ |
| ⚙️ **詳細な設定** | 音量閾値（%）と無音マージン（秒）を細かく調整可能 |
| 🤖 **AIモデルの選択** | `tiny` / `base` / `small` / `medium` / `large-v3-turbo` / `large-v3` から、速度と精度に合わせて選べます。日本語特化の `kotoba-whisper`（実験的）と、英語専用の `distil-large-v3` もあります |
| 🌐 **多言語対応UI** | 実行中にいつでも日本語・英語を切り替え可能 |
| 📁 **ドラッグ＆ドロップ** | 動画ファイルをウィンドウにドロップするだけで選択完了 |
| 📦 **環境構築不要** | 単一の `.exe` で動作 — Python不要、依存関係のインストール不要 |
| 🔒 **オフライン・外部送信なし** | 録音・録画のデータは、外部サービスへ送りません。モデルを取得したあとは、インターネットなしで使えます |
| 🎙 **音声区間検出カット** | 音量しきい値と音声区間検出（Silero VAD）を選択。無音をカットせず倍速にもできる |
| 〰 **波形プレビュー** | 処理前に「どこが切られるか」を波形で確認。時間の方向と、波形の大きさの方向を、それぞれ拡大・縮小できます |
| ✋ **手動のカット・倍速** | 波形をドラッグするか、開始と終了を数値で入れて、区間を削除・倍速にします。自動のカットに重なって、すぐ波形に出ます |
| ✂ **字幕を消すと同時にカット** | 字幕の確認・編集画面で字幕を削除すると、その区間の映像・音声もカットします。字幕とタイムラインを書き直します |
| 🔁 **続きから編集** | 保存した編集セッション（`<名前>.snipsync.json`）を開くと、話者名・変更の印・元の動画・手動の区間が戻ります |
| 🧹 **文字起こしの清書（LLM）** | PC 上の LLM（文章は PC の外へ出ません）か、チャットに貼る用のファイルで、句読点の補いと聞き間違いの修正をします |
| 🧩 **バッチ処理・音声ファイル** | 複数ファイル／フォルダを一括処理。音声のみの入力とカット済みメディア書き出しに対応 |
| 🈶 **読みやすい字幕** | 日本語の文節改行（BudouX）、用語辞書、話者分離（任意） |
| 📄 **字幕全文の書き出し** | 全文を `.txt` / `.md` / `.srt` でプレビュー・保存 |
| 📍 **タイムラインマーカー** | カット点・話者交代・字幕の先頭のマーカーを任意で追加（DaVinci Resolve 21 で確認済み。Premiere Pro・Final Cut Pro は未検証） |

## 🚀 インストール

### 方法A: ビルド済みEXEを使う（推奨）

> Python も FFmpeg も、他のソフトも不要です。

1. [Releases](https://github.com/R3NeR3N/SnipSync/releases/latest) ページから `SnipSync.exe` をダウンロードします。
2. 好きな場所（デスクトップなど）に置きます。
3. `SnipSync.exe` をダブルクリックして起動します。

**初回のダウンロード**（インターネット接続が必要。1回だけ）:

| 内容 | いつ | サイズ |
|---|---|---|
| Whisper モデル | そのモデルで初めて字幕を作るとき | `tiny` 0.08GB ・ `base` 0.15GB ・ `small` 0.49GB ・ `medium` 1.5GB ・ `large-v3-turbo` 1.6GB ・ `large-v3` 3.1GB ・ `distil-large-v3` 1.5GB ・ `kotoba-whisper` 1.5GB |
| 話者分離モデル | **話者を分けて表示** を初めてオンにしたとき | 約35MB |
| GPU 用の部品（cuBLAS・cuDNN） | **GPU を使う** をオンにして処理を開始し、取得を許可したとき（NVIDIA の GPU のみ） | 約1.4GB（保存後は約2.1GB） |

> **💡 保存場所と削除方法**
> - Whisper モデル: `C:\Users\<ユーザー名>\.cache\huggingface\hub`
> - kotoba-whisper、話者分離モデル、プリセット: `%APPDATA%\SnipSync`
> - GPU 用の部品: `%APPDATA%\SnipSync\cuda`（画面の **GPU を使う** の横にある **部品の保存先** ボタンで開けます）
>
> `SnipSync.exe` を削除しても、これらは残ります。ディスクを空けたいときは、上のフォルダを手動で削除してください。
>
> GPU 用の部品は、SnipSync 専用のコピーです。Windows にも、ほかのアプリにも入れていないので、**削除しても問題ありません**。ほかのアプリには影響しません。SnipSync は、次に GPU を使うときに、取得してよいかをもう一度聞きます（CPU なら、部品なしでそのまま使えます）。

**更新の確認:** 起動時に 1 日 1 回、GitHub に新しい版が出ていないか、取得済みの Whisper モデルが Hugging Face で変わっていないかを問い合わせます。見つかると **更新** 画面が開きます。そこでボタンを押すまで、何も入れ替えません。確認は、画面右上の **更新** ボタンからオフにでき、**今すぐ確認** で手動でも行えます。送るのは GitHub と Hugging Face の通常の問い合わせだけで、ファイルや設定は送りません。SnipSync 本体は GitHub の公式リリースから取得し、SHA-256 が一致したときだけ入れ替えます。モデルを更新しても、古い版はディスクに残ります。

### 方法B: ソースから実行する

#### 前提

- Windows 10 / 11（64bit）
- [Python](https://www.python.org/downloads/) 3.10 以上（インストーラーで **Add python.exe to PATH** にチェックを入れてください）
- [Git](https://git-scm.com/downloads)（または GitHub からリポジトリを ZIP でダウンロードして展開）
- FFmpeg は**不要**です。

#### 手順（PowerShell またはコマンドプロンプト）

```bash
git clone https://github.com/R3NeR3N/SnipSync.git
cd SnipSync
python -m venv .venv
.venv\Scripts\python.exe -m pip install -e .
.venv\Scripts\python.exe -m snipsync
```

`python -m venv .venv` は `SnipSync` フォルダの中に独立した環境を作るので、PC 全体には何もインストールされません。消すときは `.venv` フォルダを削除するだけです。

初めてファイルを処理するとき、SnipSync が auto-editor 31.7.2（約45MB）を公式の GitHub リリースから取得し、SHA-256 を照合してから使います。

---

### 方法C: EXEを自分でビルドする（PyInstaller）

上の手順のあと、同じ `SnipSync` フォルダで実行します。

```bash
.venv\Scripts\python.exe -m pip install -e ".[build]"
.venv\Scripts\python.exe scripts\fetch_auto_editor.py
.venv\Scripts\python.exe -m PyInstaller build\app.spec
```

`fetch_auto_editor.py` は、EXE に同梱するための auto-editor を取得します（SHA-256 検証つき）。出力は `dist\SnipSync.exe` です。

**EXE（またはソースの実行）は、最新か:** 開発中は、版の番号（`0.3.0`）が変わりません。そこで、自分の PC で作った EXE は、ヘッダーの版の横に、ソースの中身から計算した ID を、`v0.3.0 · dev 1a2b3c4` の形で出します。マウスを重ねると、コミット・未コミットの変更の有無・印を作った時刻が出ます。ソースを直して作り直したあとに ID が変わっていなければ、古い EXE を開いています。ソースから実行したときは、起動のたびに ID を計算します。ID はコミットされず、GitHub Actions が作る配布版の EXE には付きません（ヘッダーは `v0.3.0` だけです）。

## ⚙️ 使用方法

### まずはこれだけ

```mermaid
flowchart LR
    A["① ファイルをドロップ<br/>(動画・音声・フォルダ)"] --> B["② 設定を確認"] --> C["③ ▶ 処理を開始する"] --> D["④ 編集ソフトへ取り込む"]
```

> スクリーンショットは、合成音声2人分の短いサンプル録音を処理したときの画面です。画面は日本語／英語に対応しています（右上の「言語」で切り替え）。

#### 1. メイン画面

<p align="center"><img src="docs/images/main_ja.png" width="640" alt="番号つきで説明した SnipSync のメイン画面"></p>

| # | 場所 | 内容 |
|:-:|---|---|
| ① | ファイルを選ぶ／解除 | 動画・音声ファイル（複数・フォルダも可）は、波形の部分にドロップしても入れられます。「ファイルを選ぶ…」で選ぶこともできます |
| ② | 波形 | 処理する*前*に、どこが切られるかが見えます。**赤**が削除、**青**が倍速、灰色が残る部分です。波形をクリックすると、再生位置がそこへ移ります。ドラッグで区間を選ぶと、手動のカット・倍速にできます。下のボタンで、拡大・縮小もできます |
| ③ | 再生 | 前のカット／再生／次のカットと、再生速度（0.5〜4倍）。切った結果を、処理の前に聞けます |

| ⑧ | 出力フォルダを開く／字幕を確認・編集 | 処理が終わると押せます |
| ⑨ | ログ | 処理の経過が出ます |

#### 2. 開始してログを見る

<p align="center"><img src="docs/images/result_ja.png" width="640" alt="処理後のメイン画面（ログ表示）"></p>

下の**ログ**に、カット、音声認識（認識したテキスト付き）、話者分離、書き出したファイルが順に表示されます。終わると、**出力フォルダを開く** で、出力先を開けます。

出力は、入力ファイルと同じフォルダ（または指定したフォルダ）に作られます。**処理ごとに日時のフォルダーを作る**（既定でオン）のときは、その中に `日時_モデル名` のフォルダ（例: `2026-10-04_190357_large-v3`）が作られ、ファイルはすべてそこに入ります。作られるタイミングは2回あります。

**① 「処理を開始」を押したあと、処理が進む間に作られるもの**

| ファイル | 内容 |
|---|---|
| `<名前>_snipsynced.fcpxml` / `.xml` | カット済みのタイムライン。カットが終わった時点で作られます。複数の音声トラックを持つ動画で `.fcpxml` を選んだときは、音声を取り出した `<名前>_tracks` フォルダも作られます（`.fcpxml` の隣に置いたままにしてください） |
| `<名前>_snipsynced.mp4` / `.mov` / `.mkv` / `.wav` … | 出力形式が「動画・音声」のときの、カット済みの動画／音声 |
| `<名前>_temp_audio.wav` などの作業用ファイル | 字幕づくりの途中だけ存在し、処理が終わると自動で消えます |

**② 字幕の確認・編集画面で「保存」を押したとき**

「保存する前に確認する」がオン（既定）のとき、処理は字幕の確認・編集画面で止まります。この間、字幕ファイルはまだありません。「保存」を押すと、**直した内容のまま**、次のファイルが1回だけ作られます。

| ファイル | 内容 |
|---|---|
| `<名前>.srt` | 字幕。話者名（外せます）と、1行の折り返しを反映します |
| `<名前>.txt` | 字幕全文。「.txt（文字起こし）」にチェックを入れたときだけ。時刻を付けるかは、画面の「時刻を含める」に従います |
| `<名前>.md` | 見出しつきの字幕全文。「.md（文字起こし）」にチェックを入れたときだけ |

- 画面の下に「保存先: …」と出ます。「名前を付けて保存…」は、いま表示している形式の1ファイルだけを、選んだ場所に書きます。
- 保存せずに閉じると、字幕ファイルは作られません（タイムラインや動画は、①の時点ですでにあります）。
- 画面を閉じると、処理の続きが進みます。最後のファイルでは、メイン画面のログに「処理が完了しました」と出ます。
- 「保存する前に確認する」をオフにすると、字幕ファイルは①の時点で作られます。あとから **字幕を確認・編集** で開き直して直し、保存し直すこともできます（同じファイルを上書きします）。
- 話者交代のマーカー（**マーカー（実験的）** をオンにしたとき）は、字幕を保存した直後に、**直したあとの話者と話者名**で追加します。カット点のマーカーは、①の時点でタイムラインに入っています。保存せずに閉じると、話者交代のマーカーは入りません。**保存する前に確認する** をオフにしたときは、①の時点の字幕から入ります。（Resolve では、`_markers.edl` を書き直します。下の注意を参照）
- 話者名は、画面の下の **話者名を付ける** で付けるか外すかを選べます。オフにすると、保存・コピー・プレビューの `.srt` / `.txt` / `.md` から `話者1：` が消えて、本文だけが残ります。最初はオンです。話者が1人も付いていないときは押せません。話者交代のマーカーには効きません。

| # | 表示内容 |
|:-:|---|
| ① | 処理前 → 処理後の長さ、短縮率、カットの数 |
| ② | 色の説明（残る／削除／倍速） |
| ③ | **確認し直す** — カットの設定を変えたら、押して計算し直します |
| ④ | 再生、前後のカットへの移動、再生速度 |
| ⑤ | 波形の上の帯。**赤** = 削除される部分、**青** = 倍速になる部分。灰色は残ります |
| ⑥ | 拡大・縮小。**時間** と **波形の大きさ** のボタン、**全体**、スクロールバー |
| ⑦ | 手動のカット・倍速。区間をドラッグするか、**数値で指定** を押して、**削除する** / **N 倍速にする** |

**波形の拡大・縮小:** **時間** のボタン（または、波形の上でマウスのホイール）で、時間の方向に、0.5 秒の幅まで拡大・縮小できます。カーソルの下の位置は動きません。拡大しているときは、Shift + ホイールか、スクロールバーで左右に動かし、**全体** で、全部を表示します。**波形の大きさ**（または Ctrl + ホイール）で、波形の縦を大きくして、小さな音も見えるようにします。拡大しても、カットの結果は変わりません。

**数値で区間を指定:** **数値で指定** を押す（再生位置から 5 秒の区間ができます）か、先にドラッグで区間を選んでから、**開始** と **終了** を、`90`、`1:30`、`1:30.25`、`0:01:30.250` の形で入れます。Enter で確定します。読めない値や、開始より前の終了は、直前の区間に戻ります。動画の長さをこえる分は、動画の長さまでになります。

**手動のカット・倍速:** 波形をドラッグして区間を選び、**削除する**、または **N 倍速にする**（N はカットタブの倍率）を押します。区間は、自動のカットに重なって、すぐ波形に出るので、再生して確かめられます。**手動の編集 N 件…** で、一覧を見て、1 件ずつ外せます。削除は必ずカットになり、倍速は、残る部分だけに効きます。選んでいる動画だけに効き（別の動画を選ぶと消えます）、**処理を開始** で、タイムライン・字幕の時刻・編集セッションにも反映されます。倍速にした部分は、字幕を作る音声も倍速になるので、速すぎると、文字起こしが乱れることがあります。

<p align="center"><img src="docs/images/manual_ja.gif" width="760" alt="手動のカット・倍速の操作。区間を選び、開始・終了を数値で直し、削除して赤に、別の区間を倍速にして青に、時間と波形の大きさを拡大し、手動の編集の一覧を開く"></p>

動画は、区間を選び、開始と終了を数値で直し、**削除する**（赤）、**N 倍速にする**（青）、時間と波形の大きさの拡大、の順です。**手動の編集 N 件…** を開くと、決めた区間の一覧が出て、1 件ずつ外せます。

<p align="center"><img src="docs/images/manual_list_ja.png" width="420" alt="手動の編集の一覧。区間ごとに、削除か倍速か、開始・終了・長さが出て、1 件ずつ外せる"></p>

#### 4. （任意）字幕を確認して直す — 字幕の確認・編集画面

<p align="center"><img src="docs/images/editor_ja.png" width="640" alt="番号つきで説明した字幕の確認・編集画面"></p>

| # | できること |
|:-:|---|
| ① | 字幕の一覧。行を選ぶと、下で直せます。Shift や Ctrl で複数の行を選ぶと、まとめて変えられます。直した行には印が付きます |
| ② | 元に戻す／やり直す。どの編集も戻せます |
| ③ | 表示の切り替え。編集のほか、`.txt` / `.md` / `.srt` に書かれる内容を、そのまま確認できます |
| ④ | 選んだ字幕の本文を直します |
| ⑤ | 話者の変更（選んだ行すべてに効きます）と、「山田」のような話者名の入力 |
| ⑥ | カーソル位置で分ける、次の字幕と結合、最初に戻す、削除 |
| ⑦ | **時刻を含める**（`.txt` / `.md`）と **話者名を付ける**。保存・コピーされる内容が変わります |
| ⑧ | **保存**。隣に、名前を付けて保存、コピー、開くがあります |

- **話者タブ:** 話者ごとの発話時間・件数・割合の一覧です。話者分離は、1 人を何十ものラベルに分けてしまうことがあります。同じ人のラベルを選んで **まとめる** と、1 つの話者になります。**サンプルを聞く** は、その話者のいちばん長い字幕をメイン画面で再生するので、誰の声かを確かめられます。**名前を付ける** で名前も付けられます。自動で整理する機能が 2 つあり、発話の合計が少ない話者（初期値は 30 秒未満）と、同じ話者に前後を挟まれた短い発言を、時間の近い話者へ寄せます。適用の前に、話者が何種類に減るかを見せます。**番号を振り直す** は、よく話した順に番号を付け直します。どの操作も元に戻せます。

<p align="center"><img src="docs/images/editor_speakers_ja.png" width="640" alt="話者タブ。話者ごとの発話時間・件数・割合の一覧"></p>

- **時刻を押す**（一覧の時刻、または本文の上の時刻）と、メイン画面のプレビューが、その字幕の頭から再生されます。メイン画面で動画を選び、カットマップが出ているときに使えます。
- **字幕を消すと同時に、映像・音声もカットする:** 字幕の下の **削除したら、映像・音声もカットする** をオンにして字幕を削除すると、その字幕の区間（前後に **余白** を足した範囲。初期値は 0.1 秒）に、カットの印が付きます。メイン画面で同じ動画を開いていれば、カットマップにも出ます。元に戻すと、印も消えます。**保存** を押すと、確認のあと、字幕の時刻を詰め直して保存し、タイムラインを同じ場所へ上書きします。**名前を付けて保存** は、字幕とタイムライン（`<名前>_snipsynced.<拡張子>`）を新しい名前で書き、元のファイルは変えません。タイムラインの書き直しに失敗したときは、そのことが記録され、次の保存でやり直します。使えるのは、字幕の保存前の確認中でないとき、かつ、書き出しが動画・音声ファイルそのものでないときです。

<p align="center"><img src="docs/images/cut_ja.gif" width="640" alt="字幕を消すと同時にカットする操作。字幕を選び、スイッチをオンにして削除し、カットの印をカットマップで確かめ、保存してタイムラインを書き直す"></p>

動画は、字幕を選び、スイッチをオンにして削除し、メイン画面のカットマップに赤い印が出るのを確かめ、**保存** でタイムラインを書き直すまでの流れです。

- **字幕（.srt）の置き場所:** 保存のたびに、メイン画面のログに、最初の字幕がタイムラインに出る時刻（例: `00:00:23:10`）を出します。DaVinci Resolve は、SRT を読み込むとき、最初の字幕より前の空白を詰めるので、字幕トラックの左端（最初の字幕）を、その時刻に置いてください（読み込んだ時点で、すでにその時刻にあれば、動かす必要はありません）。冒頭を倍速やカットにしたときは、最初の字幕の時刻が、0 秒から離れます。タイムラインのマーカーを入れる設定のときは、同じ時刻に、緑のマーカー **字幕の先頭** も入ります。
- **アプリを閉じても、続きから直せます:** 保存すると、出力のそばに `<名前>.snipsync.json` も書きます。アプリを再起動したあと、メイン画面の **出力済みを開く…** か、編集画面の **開く…** で読み込むと、話者名、変更の印、元の動画、カットの設定が戻ります。`.srt` だけでも開けます。その場合は、`話者N：` が話者として読まれますが、話者名・変更の印・動画は戻りません。
- **清書…（LLM）:** 読みやすく整えた文字起こしを、LLM で、句読点の補いと、明らかな聞き間違いの修正をします。方式は 2 つです。**PC 上の LLM** は、この PC で動いている OpenAI 互換のサーバー（Ollama・LM Studio・llama.cpp server）に接続します。接続先は `127.0.0.1` / `localhost` だけなので、文章は PC の外へ出ません。モデルは、自分で用意して、名前を入れます。**貼り付け用ファイル** は、`<名前>_polish` フォルダーに、`00_使い方.md` と、`01.txt`、`02.txt`…（指示文と本文。文字数は選べます）を作ります。普段使っているチャットに貼る用で、その場合、文章はそのサービスへ送られるので、先に確かめてください。LLM には、要約や内容の追加をしないよう指示し、返ってきた行は、長さが元に近いものだけ受け入れます（合わない行は、元の文のままです）。結果は `<名前>_polished.txt` / `.md` に書き、`.srt` と編集中の字幕は変えません。

<p align="center"><img src="docs/images/polish_ja.png" width="560" alt="清書の画面。方式（PC 上の LLM／貼り付け用ファイル）の選択と、接続先・モデル・文字数の入力"></p>

<p align="center"><img src="docs/images/polish_paste_ja.png" width="560" alt="清書の画面。「貼り付け用ファイル」を選んだときの、1 ファイルの文字数の入力"></p>


<p align="center"><img src="docs/images/editor_ja.gif" width="640" alt="字幕の確認・編集画面の操作。複数の行を選び、話者をまとめて変え、名前を付け、.srt の表示で確認し、話者名を外す"></p>

動画は、複数の行を選んで話者をまとめて変え、名前を付け、`.srt` の表示で確かめ、**話者名を付ける** をオフにするまでの流れです。

#### 5. 編集ソフトへ取り込む

下の「[編集ソフトへの取り込み](#編集ソフトへの取り込み)」を参照してください。

### 設定項目

| 設定 | 内容 |
|---|---|
| **話の前後に残す余白** | カットの前後に残す余白（既定 `0.20秒`） |
| **音量のしきい値** | これより小さい音を無音とみなす基準（既定 `4.0%`）。「音声区間検出」では使いません |
| **カット方式** | 「音量しきい値」または「音声区間検出 (VAD)」。VAD は人の声以外をすべて切るので、環境音があっても安定しやすくなります |
| **無音の扱い** | 「カットする」は無音を削除。「倍速にする」は無音を残したまま、指定の倍速（既定×8）で再生します |
| **出力形式** | DaVinci Resolve / Premiere Pro / Final Cut Pro / 「カット済みメディア」（書き出し済みの動画・音声） |
| **処理ごとに日時のフォルダーを作る** | 既定でオン。保存先の中に `日時_モデル名`（例: `2026-10-04_190357_large-v3`）のフォルダを作って、そこへ書き出します。処理のたびに別のフォルダになるので、前の結果を上書きしません。複数ファイルをまとめて処理したときは、全部が同じフォルダに入ります。字幕を作らないときは、日時だけです。`.fcpxml` は音声（`_tracks`）の場所を絶対パスで持つので、取り込んだあとは、フォルダを移さないでください。移したときは、Resolve のダイアログで「はい」を選び、`_tracks` フォルダを指定します |
| **字幕を作る** | Whisper で `.srt` を作ります |
| **保存する前に確認する** | 既定でオン。字幕を作ったあと、字幕の確認・編集画面で止まります。直してから保存します |
| **AIモデル** | `tiny`/`base`/`small` は高速。**精度重視なら `large-v3-turbo` を推奨**。`kotoba-whisper` は日本語特化ですが実験的（単語の時刻が粗い）。`distil-large-v3` は英語専用 |
| **GPU を使う** | 任意。NVIDIA の GPU が必要。部品（約1.4GB）は、初回に取得してよいか確認します |
| **カットごとに字幕を区切る** | カットごとに字幕を区切り、クリップと字幕の位置を揃えます |
| **1行の文字数** | 日本語を文節の途中で改行せず（BudouX）、1字幕を2行に収めます。`0` で無効（既定 `20`） |
| **話者を分けて表示** | 誰が話しているかを `話者1：…` のように付け、話者が変わると字幕を分けます。人数が分かっているときは **人数**（2〜20）を指定してください。いちばん正確です。**自動** のときは、声が近い小さなラベルを大きなラベルへ寄せますが、残ったものは、字幕の確認・編集画面の話者タブで直せます |
| **句読点を補う** | 日本語の文字起こしに、「、」「。」「？」を補います。Whisper に句読点入りの見本文を渡し、語と語の間の無音の長さも使います。`.txt` / `.md` と編集画面に入り、字幕の `.srt` には付けません |
| **文字起こしを読みやすく整える** | `.txt` / `.md` で、ある人の発言の途中に挟まった、別の人の短い発言（8 字以下）を、文の途中に「（話者2：はい）」と入れて、文が割れないようにします。長い発言は、文の終わりで段落に分けます。字幕の `.srt` は変わりません。編集画面の **読みやすく整える** で、切り替えられます |
| **あわせて保存**（**.txt（文字起こし）**・**.md（文字起こし）**） | 字幕全文（話者・時刻つき）を字幕の隣に保存します |
| **マーカー（実験的）** | すべてのカット点と話者交代をタイムラインにマーカーとして追加します。Resolve だけは、別ファイル `<名前>_markers.edl` に書き出します（実験的。下の注意を参照） |
| **用語辞書** | カンマ区切りで、Whisper に優先してほしい語（人名・製品名など）を書きます |
| **プリセット** | 設定一式を保存・呼び出し。起動時には前回の設定が復元されます |

### 用途別の手順

- **話している動画 → DaVinci Resolve で字幕つき**: 出力形式「DaVinci Resolve」、字幕オン、モデル `large-v3-turbo`。`.fcpxml` を取り込み、続けて `.srt` を取り込みます。
- **複数人のインタビュー・ポッドキャスト**: **話者を分けて表示** をオン（人数が分かれば **人数** も指定）、**.md（文字起こし）** にチェック。話者つきの字幕と、読みやすい文字起こしが得られます。
- **騒がしい部屋・BGMあり**: **カット方式** を「音声区間検出 (VAD)」にします。
- **間は残して、速く流したい**: **無音の扱い** を「倍速にする」にします。
- **録音がたくさんある**: フォルダごとドロップします。AIモデルは1回だけ読み込んで使い回します。
- **きれいな音声ファイルだけ欲しい**: `.wav` / `.m4a` / `.mp3` をドロップして「カット済みメディア」を選びます。`.wav` が出力されます（下の注意を参照）。

### 編集ソフトへの取り込み

メニュー名はバージョンによって少し異なります。

| 編集ソフト | タイムライン | 字幕 |
|---|---|---|
| DaVinci Resolve | ファイル → 読み込み → タイムライン… で `.fcpxml` を選ぶ | ファイル → 読み込み → 字幕…、または `.srt` をタイムラインへドラッグ |
| Premiere Pro | ファイル → 読み込み で `.xml` を選ぶ | `.srt` を読み込み、シーケンスへドラッグ |
| Final Cut Pro | ファイル → 読み込み → XML… で `.fcpxml` を選ぶ | ファイル → 読み込み → キャプション… |

### 注意

- **4Kのメディア書き出し**: 同梱の auto-editor（ライセンスキー無し）は、書き出し結果を 3200×1800 以下へ自動で縮小します。開始前に SnipSync が警告します。**タイムライン出力は影響を受けません**。フル解像度で作業するときはこちらを使ってください。
- **音声のみのカット済みメディア**は `.wav` / `.flac` / `.ogg` / `.opus` で書き出します。`.mp3` / `.m4a` / `.aac` / `.wma` は、同梱の auto-editor にエンコーダーが無いため `.wav` になります。
- **マーカー**は実験的です。DaVinci Resolve 21 では、取り込めることを確認しました。Premiere Pro と Final Cut Pro では、まだ確認していません。**DaVinci Resolve は `.fcpxml` のマーカーを読み込まない**ので、Resolve 向けのマーカーは、別ファイル `<名前>_markers.edl` に書き出します（カット点は青、話者交代は黄、字幕の先頭は緑）。Resolve のメディアプールで、マーカーを付けたいタイムラインの**アイコンを右クリック**し、**タイムライン > 読み込み > EDLからタイムラインマーカー…**（英語表示では Timelines > Import > Timeline Markers from EDL）を選んで、このファイルを読み込んでください。何もない場所を右クリックして出る「タイムライン > 読み込み > AAF / EDL / XML…」は別の機能です。そちらで読み込むと、EDL が、1 フレームずつのクリップを並べた別のタイムラインになります。EDL の時刻は、タイムラインの開始タイムコードに合わせてあります。Premiere Pro と Final Cut Pro では、マーカーはタイムラインのファイルの中に入ります。
- **カット結果は SnipSync 0.1.0 と変わります**: 新しい auto-editor は短すぎるカットやクリップも除くため（`--smooth`）、カット数が減り、1つが長くなります。
- 字幕は最初に話した語から始まるので、各字幕はクリップの先頭より少し後に始まります。これは仕様です（余白は無音で残しています）。
